# PM PRD Routing Guard

## Decision

PRD/产品方案/原型任务必须：
1. 先定位和阅读用户引用的 PRD、HTML mockup、样本、接口文档、当前工作流和确认的业务边界
2. 在起草前提取"上下文包"：从源中提取稳定事实
3. 将 PRD 的生产与上下文包绑定

## 常见失败模式

- 从模板开始而非从上下文开始
- 跳过源检查
- 起草后才读引用文档
- 通用语言替代具体业务规则
- 未确认利益相关者分解
