# Self-Evolution System

## Purpose

将外部想法、用户纠正、仓库评估、技能和工作流失败转化为持久的操作改进。不自动视新项目或文章为正确。

## Intake Rule

每条自进化来源应记录：
- 日期
- 来源 URL 或本地路径
- 用户为何引入
- 评估
- 采纳策略
- 拒绝或推迟部分
- 输出位置
- 验证状态

## Adoption Policy

- 吸收原则，不是整个项目
- 小耐久规则 > 大脆弱框架
- 新技能/插件 = 覆盖增加，不是智力增加
- 声称的改进仅在真实验证后成立
